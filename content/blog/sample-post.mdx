## How a guide is organized

A finished guide opens with the training problem, then walks through one way to handle it. The words below are generic stand-in copy so the spacing, type, and color can be reviewed.

A workout log is a written record of the session. You note the exercise, how many sets and reps you did, and the load you used. The next session can start from that record. A guide about logging would explain that habit, and it would link the source for any claim about why the habit helps.

### What the log records

The table is sample markup. The cells are labels, not measurements from a session and not results from a study.

| What you write down | What that line is for |
| --- | --- |
| Exercise | Names the lift for that session |
| Sets and reps | Records the work that was done |
| Load | Records the weight that was used |

## Reading the page

Short sections keep a long guide from turning into a wall of text. A real article would use the same heading sizes you see here.

- One idea per section.
- A table only when the information is a table.
- A figure only when the picture adds something the words do not.
