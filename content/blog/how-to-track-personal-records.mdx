To track personal records in the gym, decide what counts as a PR for each lift, record it in your log the moment it happens, and only compare it with the same exercise done the same way. A PR can be more weight, more reps at a weight, or more total work, so define the type before you celebrate it.

## Types of personal records

A PR is your best performance on an exercise in a specific way. Common types:

| PR type | What it means | Example |
| --- | --- | --- |
| Weight PR | Heaviest weight for a set number of reps | First time squatting 100 kg for 5 |
| Rep PR | Most reps at a given weight | 12 reps at 60 kg, up from 10 |
| Volume PR | Most total work for an exercise in a session | More sets x reps x weight than ever before |
| Heaviest single | Heaviest weight lifted for 1 rep | A tested one-rep max |

Rep PRs happen much more often than weight PRs, especially with [double progression](/blog/double-progression). Counting them keeps progress visible between bigger jumps.

## How to track personal records in the gym

1. **Use consistent exercise names**, so each lift has one history.
2. **Log every set as you finish it**, with weight and reps.
3. **Mark the PR** in your notes or let your tracker flag it.
4. **Compare like with like.** A paused bench PR and a regular bench PR are different records. So are a high-bar and a low-bar squat.

## Keep PRs honest

A PR only counts if the rep would count last week too. Keep range of motion and technique the same. A deeper squat or a full lockout at a lighter weight is more useful information than a heavier, shorter rep. If you change equipment, such as a new bar or machine, start a new record for it. If a lift causes pain, stop and consult a qualified professional.

## An example

Illustrative PR log for a bench press over a month:

| Date | Best set | PR? |
| --- | --- | --- |
| Week 1 | 60 kg x 8 | Starting point |
| Week 2 | 60 kg x 9 | Rep PR at 60 kg |
| Week 3 | 62.5 kg x 8 | Weight PR for 8 reps |
| Week 4 | 62.5 kg x 8 | Same, no PR |

Two PRs in four weeks, with a repeat week in between, is a normal pattern.

## Use PRs to plan your training

PRs show which lifts are moving. When one lift has not set a PR in several weeks, it may need attention. A [weekly review](/blog/how-to-review-your-training-week) is a good time to check. For the logging basics, see [how to track your workouts](/blog/how-to-track-your-workouts).
