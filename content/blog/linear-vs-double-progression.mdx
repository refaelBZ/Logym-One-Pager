Linear progression vs double progression comes down to what changes each session. With linear progression, you keep the same sets and reps and add a small, fixed amount of weight every time you succeed. With double progression, you keep the weight and add reps within a range, then add weight once you reach the top of that range on every set.

## How linear progression works

Pick a set and rep scheme, such as 3 sets of 5. Each session you complete all the reps, you add a small amount of weight next time, for example 2.5 kg on a barbell lift. If you miss reps, you repeat the weight. It is simple to follow and easy to log, which is why many beginner barbell programs use it, including the [5x5 workout program](/blog/5x5-workout-program).

## How double progression works

Pick a rep range, such as 3 sets of 8 to 12. Stay at one weight and add reps session by session. When every set reaches 12, add the smallest weight jump and start again near 8. The full method is in the [double progression](/blog/double-progression) guide.

## Linear progression vs double progression at a glance

| | Linear progression | Double progression |
| --- | --- | --- |
| What changes | Weight, every successful session | Reps first, then weight |
| Rep target | Fixed, for example 5 | A range, for example 8 to 12 |
| Best fit | Barbell lifts with small plate jumps | Dumbbells, machines, accessory lifts |
| Main limit | Stalls once small jumps stop working each session | Slower to add weight |

## Which one to choose

Choose linear progression if you are new to a barbell lift, your gym has small plates, and you like a clear target every session. Choose double progression if the next weight up is a big jump, or if you train in higher rep ranges. Many lifters use both: linear progression on the main barbell lifts and double progression on dumbbell and machine work.

## When linear progression stops

Adding weight every session cannot continue forever. When you miss reps at the same weight for a few sessions, it is a sign to change approach. A common next step is switching that lift to a rep range and using double progression. The [strength plateaus](/blog/strength-plateaus) guide covers other options.

## An example

Illustrative squat numbers with linear progression, 3 sets of 5:

| Session | Weight | Reps |
| --- | --- | --- |
| 1 | 60 kg | 5, 5, 5 |
| 2 | 62.5 kg | 5, 5, 5 |
| 3 | 65 kg | 5, 5, 4 |
| 4 | 65 kg | 5, 5, 5 |

Session 3 fell one rep short, so session 4 repeated the weight before moving on. If a lift causes pain, stop and consult a qualified professional.
