The simplest way to track workouts is to record every working set as soon as you finish it: the exercise, the weight, and the reps you actually did. Next time you repeat that workout, open last session's numbers and try to beat one of them. That habit is enough to show whether you are getting stronger.

## What to write down for each set

Keep it to the essentials:

- **Exercise.** Use the same name every time, and note the variation, such as "incline dumbbell press".
- **Weight.** One unit throughout, and for dumbbells, say whether it is per hand.
- **Reps.** What you completed, set by set, rather than what the plan said.

A short note is worth adding when something changes the numbers, like a different machine or a new grip.

## How to track workouts during the session

1. Before the first set, check what you lifted last time on that exercise.
2. Pick one target: one more rep on a set, or a little more weight.
3. Log the set during your rest, while the numbers are fresh.
4. Write the real result, even if you fell short of the target.

Logging between sets takes seconds and saves you from rebuilding the session from memory afterward.

## An example

Here is an illustrative bench press entry:

| Session | Sets |
| --- | --- |
| Last week | 60 kg x 8, 8, 7 |
| Today | 60 kg x 8, 8, 8 |

The target today was 8 reps on the third set, and the log shows it was hit. Next session, the weight can go up. That decision is the core of [progressive overload](/blog/progressive-overload).

## How to tell you are progressing

Compare the same exercise from session to session. More reps at the same weight counts as progress, and so does more weight for the same reps. A small drop in reps right after you add weight is normal. If a lift stays flat for several sessions, check the log for missed workouts or changes in technique before you switch programs. If an exercise causes pain, stop and consult a qualified professional.
